---

## 🖼️ Imágenes

Para cambiar una imagen, reemplaza el `.jpg` en `img/` con el mismo nombre.  
También puedes usar `img/1.jpg`, `img/2.jpg`... `img/6.jpg` como alternativa.

---

## 🚀 Subir a GitHub Pages

1. Crea repo en GitHub (ej: `sensis-good-ff`)
2. Sube todos los archivos
3. Settings → Pages → Source: `main` / `root`
4. Tu sitio: `https://tu-usuario.github.io/sensis-good-ff`
